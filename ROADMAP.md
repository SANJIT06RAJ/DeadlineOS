# IT Level-Up Roadmap

## Overview

- **Preparation period:** 15 October – 6 December 2026
- **Degree start date:** 7 December 2026
- **Main project:** DeadlineOS — Academic Task & Deadline Intelligence

DeadlineOS is a system for tracking academic assignments, deadlines, subtasks, progress, and reminders. Later, an optional local-AI document extraction feature suggests assignment details and **requires user confirmation before saving**.
