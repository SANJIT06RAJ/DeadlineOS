# DeadlineOS

Academic Task & Deadline Intelligence.

A portfolio project to help students manage assignments, organise subtasks, track deadlines, and reduce last-minute submissions.

## Technology Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: SQLite
- Testing: pytest
- Version Control: Git + GitHub

## Planned Features

- Assignment management
- Deadline dashboard
- Subtasks and progress tracking
- Reminders
- Optional AI-assisted assignment extraction with user confirmation

## Status

Currently in development.
