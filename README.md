# DeadlineOS

Academic Task & Deadline Intelligence

DeadlineOS helps students manage assignments, organise subtasks, track deadlines, and reduce last-minute submissions.

## Planned Technology Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: SQLite
- Testing: pytest
- Version Control: Git + GitHub
- Future: Reminders, Docker, CI/CD, and optional local AI document extraction

## Project Status

Currently in development.

## Planned Features

- Assignment management
- Deadline dashboard
- Subtasks and progress tracking
- Deadline reminders
- Optional AI-assisted assignment detail extraction with user confirmation
